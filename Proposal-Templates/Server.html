Professional Services

What we deliver alongside your hardware.

One-time engagements that get your servers racked, configured and integrated into your business properly. Each service is scoped, fixed-priced and quoted separately.

Deployment & Configuration

Unboxing, racking, OS & firmware - ready to use

We deliver the server fully built, racked and integrated into your network - not just dropped in a box at reception.

  • Site survey - power, cooling, rack space, network ports
  • Unboxing, racking & cabling (power + network)
  • BIOS / firmware update to vendor-recommended baseline
  • RAID configuration & storage provisioning
  • OS install (Windows Server / Linux / VMware ESXi)
  • iDRAC / iLO setup for remote management
  • Documentation & handover
Typical timeline: 1-2 weeks per server Pricing: Per server, see quotation

Virtualization Setup

VMware vSphere, Microsoft Hyper-V or Proxmox VE

Run multiple workloads on a single host with high availability, snapshots and live migration. We design and deploy the right hypervisor for your scale and budget.

  • Hypervisor install & cluster configuration
  • Shared storage / vSAN / Storage Spaces Direct
  • Networking - vSwitches, VLANs, NIC teaming
  • High Availability & live migration setup
  • P2V / V2V migration of existing workloads
  • Resource templates & VM provisioning standards
  • Admin training & runbook handover
Typical timeline: 2-3 weeks Pricing: Per cluster, see quotation

Backup & Disaster Recovery

Veeam, Commvault, Acronis or Dell PowerProtect

A backup you've never tested isn't a backup. We design, deploy and test backup & DR solutions aligned to your RPO and RTO targets, with off-site / cloud copies for ransomware protection.

  • RPO / RTO assessment & backup policy design
  • Backup software install & repository sizing
  • 3-2-1 strategy - on-site, off-site, immutable cloud copy
  • Application-aware backups (SQL, Exchange, AD, file)
  • DR site / replication setup (where applicable)
  • Quarterly test restores & DR drills
  • Documented recovery runbooks
Typical timeline: 2-4 weeks Pricing: Per workload set, see quotation

Server Centralization & Remote Desktop

Active Directory, file server, RDS / Citrix, branch consolidation

Consolidate scattered desktops, branch servers and shared drives into one well-governed central server. Users get the same office experience - from the office, home, branch or client site.

  • Active Directory / DNS / DHCP / Group Policy design
  • Centralised file server with quotas & access controls
  • Remote Desktop Services (RDS) farm or Citrix VAD
  • Branch-office VPN / SD-WAN integration
  • Profile management & printer redirection
  • User migration from existing servers / NAS
  • End-user training session
Typical timeline: 3-6 weeks Pricing: Per site, see quotation

Monitoring & Alerting

PRTG / Zabbix / Nagios + vendor tools (OME, OneView)

Know about a problem before your users do. We deploy and tune a monitoring platform covering hardware health, OS, applications and network - with alerts to email, SMS and Teams.

  • Monitoring tool install & agent rollout
  • Hardware health (CPU, memory, disk, fans, PSU, RAID)
  • OS / service / application probes
  • Network & bandwidth monitoring
  • Threshold tuning & alert routing
  • Dashboards & monthly executive reports
Typical timeline: 1-2 weeks Pricing: Per environment, see quotation

Server Security Hardening

CIS / Microsoft baselines + endpoint protection

A factory-default server is a soft target. We harden the OS, hypervisor and management plane against current threats and prepare your environment for audits.

  • CIS / Microsoft Security Baseline applied via GPO
  • Patch management policy & rollout schedule
  • Endpoint protection (Defender / EDR) deployment
  • Privileged Access - least privilege, MFA on admin
  • iDRAC / iLO & management network segmentation
  • Audit logging & SIEM integration (where in scope)
  • Security baseline report
Typical timeline: 2-3 weeks Pricing: Per server / per environment, see quotation

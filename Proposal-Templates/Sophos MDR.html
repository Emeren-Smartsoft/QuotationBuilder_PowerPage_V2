Why MDR, why now

The gap between detection and action is where breaches happen.

Most organisations have antivirus and firewalls. Very few have analysts available at 2 AM on a Sunday to act on the alert that matters. Sophos MDR closes that gap - with humans, not chatbots.

Alerts no one will read

Modern security tools generate hundreds of alerts per week. Without a SOC, the one that mattered gets buried until Monday.

Attackers move in minutes

Modern ransomware encrypts a typical server estate in under 90 minutes. Detection without response is just watching it happen.

Building your own SOC is brutal

A 24x7 in-house SOC needs 6+ analysts, costs Rs.2 Cr+ per year and takes 18 months to hire. Sophos MDR replaces it for a fraction of the cost.

Solution Components

Two licence components. One MDR coverage.

The Sophos MDR solution is licensed per protected workload. Server licences and endpoint licences combine into a single managed service, run from one Sophos Central console by one Sophos SOC pod assigned to your account.

Component 1 - Servers

Sophos MDR - Server Licence

Per physical or virtual server, 24x7 monitored.

  • 24x7 monitoring of every in-scope server (Windows / Linux / virtualised)
  • Active threat response - Sophos analysts isolate hosts, kill processes, block IPs
  • Server-grade telemetry & lateral-movement detection
  • Bundled Sophos Intercept X for Server licence
  • Linux Sensor for cloud / Kubernetes workloads
  • Monthly server posture report
Scope: Physical & VM servers Term: 1 yr / 3 yr
Component 2 - Endpoints

Sophos MDR - Endpoint Licence

Per laptop, desktop or workstation. Windows + macOS.

  • 24x7 hunting + response on every laptop / PC
  • Stops ransomware, phishing payloads, credential theft
  • Bundled Sophos Intercept X Advanced licence
  • Centralised cloud console & reporting
  • Quarterly tabletop exercise with your IT team
  • Co-terminus billing with existing Sophos licences
Scope: Laptops, desktops, mac Term: 1 yr / 3 yr
